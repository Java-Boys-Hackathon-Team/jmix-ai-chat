Строки стали векторами

Heatmap, или тепловая карта, — это способ показать длинный числовой вектор цветной полосой: каждая ячейка соответствует одной координате, а цвет показывает её знак и величину. Она нужна, чтобы выровнять embeddings по одинаковым координатам и увидеть, где их числовые «отпечатки» похожи, а где отличаются.

Дальше без API. Метрики посчитает JavaScript прямо в браузере.

Четыре взгляда на близость

Метрика определяет, что именно считать «рядом»: одинаковое направление или малое расстояние между координатами.

Один пример для всех схем

У настоящего embedding сотни или тысячи координат. Здесь оставим две, чтобы формулы можно было увидеть на плоскости.

A = (Aₓ, Aᵧ) = (2, 1) B = (Bₓ, Bᵧ) = (5, 4)

Сравниваем угол θ

Cosine similarity

cos(A,B) = (AₓBₓ + AᵧBᵧ) / (√(Aₓ² + Aᵧ²) × √(Bₓ² + Bᵧ²))= (2×5 + 1×4) / (√5 × √41) ≈ 0,978
Что измеряет

Угол между векторами. Длина векторов не влияет.

Где используют

Семантический поиск, RAG, поиск дублей и похожих текстов.

Идём напрямую

Euclidean distance · L2

d₂(A,B) = √((Aₓ−Bₓ)² + (Aᵧ−Bᵧ)²)= √((2−5)² + (1−4)²) = √18 ≈ 4,243
Что измеряет

Прямое геометрическое расстояние между двумя точками.

Где используют

Поиск ближайших соседей, кластеризация и поиск аномалий, когда важно именно расстояние.

Идём по осям

Manhattan distance · L1

d₁(A,B) = |Aₓ−Bₓ| + |Aᵧ−Bᵧ|= |2−5| + |1−4| = 3 + 3 = 6
Что измеряет

Сумму абсолютных разниц по всем координатам.

Где используют

Разреженные признаки и задачи, где нужно снизить влияние отдельных больших отклонений; для embeddings применяется реже.
